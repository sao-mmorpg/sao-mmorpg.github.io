SAO MMO-RPG website v4

Open index.html in a browser. No build step is required.

Main improvements in v4:
- Hover-fill navigation underline for Game / Features / Updates / Community.
- PLAY NOW opens a platform picker for Telegram or VK.
- Richer update timeline cards with screenshots.
- Floating holographic game-world objects behind the mechanics section.
- Richer multiplayer HUD.
- Telegram and VK community buttons are icon-based and separated.
- Developer Telegram and VK profiles are directly clickable.
- RU/EN remains automatic + manual.

UPDATE LOG
The Update Log is photo-free and collapsible. Add new <details class="update update-card reveal"> blocks in index.html. Each title/body has data-ru-title/data-en-title and data-ru-body/data-en-body attributes for RU/EN. The newest update should be placed at the top.
